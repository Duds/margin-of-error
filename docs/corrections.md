# Corrections

Append-only and public. An error that is silently overwritten is worse than an
error that was published, because the reader cannot tell which numbers were ever
in doubt.

---

## Policy

- Append, never edit a prior entry.
- State what was wrong, what is correct, and when it was fixed.
- If the error would have changed a reader's conclusion, say so plainly.
- If a figure was wrong in a way that favoured the site's thesis, that gets the
  same prominence as one that did not.
- The correction date and the version of the page it applies to are both
  recorded. A page is a dated artifact, like a newspaper.
